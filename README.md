# robot-loader's asset repository

This repository contains scripts that create the
[`urdf.json`](./nova2/public/nova2_robot/urdf.json) and
[`linkmap.json`](./nova2/public/nova2_robot/linkmap.json) files needed
by [robot loader](https://github.com/TSUSAKA-ucl/robot-loader.git)
from ROS URDFs.  The scripts that create the
[`shapes.json`](./nova2/public/nova2_robot/shapes.json) file are not
included here, but can be found in
[`gjk worker`](https://github.com/TSUSAKA-ucl/gjk_worker.git).

このリポジトリには、
[robot-loader](https://github.com/TSUSAKA-ucl/robot-loader.git) に必要
な`urdf.json`と`linkmap.json`を ROS URDF から作成するスクリプトが含ま
れています。`shapes.json`を作成するスクリプトは、ここには含まれておら
ず、[gjk worker](https://github.com/TSUSAKA-ucl/gjk_worker.git) に
含まれています。
